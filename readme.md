# Cinema Audience Forecasting

## 📌 Project Overview
Predicting cinema audience using machine learning techniques
based on historical booking and theater data.

## 📂 Dataset
[Cinema Audience Forecasting Dataset](https://www.kaggle.com/competitions/Cinema_Audience_Forecasting_challenge)

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
